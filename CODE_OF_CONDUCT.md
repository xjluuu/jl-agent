# Code of Conduct

JL-Agent aims to be a practical, respectful project for people building local automation in constrained environments.

## Expected Behavior

- Be respectful and direct.
- Discuss technical tradeoffs with evidence.
- Keep feedback actionable.
- Assume contributors may be working under different company restrictions.

## Unacceptable Behavior

- Harassment, threats, or personal attacks
- Publishing private information or credentials
- Intentionally submitting malicious code
- Spam or off-topic promotion

## Enforcement

Maintainers may edit, hide, or remove comments and contributions that violate this code of conduct. Repeated or severe violations may result in a ban from project spaces.

Report issues privately to the maintainer email listed in the repository profile, or open a private security advisory if available.
