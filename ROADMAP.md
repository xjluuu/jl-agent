# Roadmap

## v0.1 - Public Foundation

- Clean public repository
- Single-file runtime
- External config
- Self-check and release-check
- Windows EXE build script
- Audit log
- Dangerous command blocking
- Project scan and verification pipeline

## v0.2 - Reliability and Permission Hardening

- Offline smoke test for no-API environments
- Documented permission matrix
- Role-boundary regression checks
- Clearer task plan / execute / verify loop
- Safer refusal behavior for non-admin development requests

## v0.3 - Demo and Packaging

- Demo GIFs
- Windows x64 release artifact
- Offline wheels documentation
- Better dashboard screenshots
- More explicit enterprise deployment docs

## v0.4 - Local Plugin Protocol

- Local plugin manifest format
- Tool discovery from a plugins folder
- Plugin permission metadata
- Example local plugin

## v0.5 - Code Index

- Local SQLite code index
- File symbol summary
- Faster project analysis
- Better change impact hints

## v0.6 - Optional Browser Automation

- Optional Playwright/Selenium package
- Browser automation self-check
- Separate packaging profile for browser-enabled builds

## Non-Goals

- Mandatory cloud dependency
- Mandatory Docker
- Full hosted sandbox replacement
- Public plugin marketplace dependency
