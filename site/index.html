JL-Agent

一个能在内网、共享盘、Windows EXE 和本地 Python 环境中落地的企业级 AI Agent。它不是聊天壳，而是带权限、审计、知识库、工程工具和 A 股投研日报桥接的本地工作台。

Built for the company PC you actually have.

No Docker assumption. No public plugin marketplace dependency. No requirement that every coworker has Python. JL-Agent keeps runtime config, storage, permission boundaries and release checks explicit.

One file, serious workflow

Run as Python during development, package as EXE for users without Python, and keep API/model/storage settings outside the executable.

$ python xjlagent.py --self-check
[OK] config, storage, permissions, dependencies
$ python xjlagent.py --dashboard
Dashboard: http://127.0.0.1:18888

Agent controls, not just chat

Project scan, verification suggestions, audit logs, local knowledge ingestion, parallel research, Risk Agent veto and scheduled tasks live behind role-based permissions.

AdminRun commands, install cron, scan projects, manage users.
MaintainerAdd approved knowledge and reusable workflows.
ViewerUse safe chat, documents, research and /stock report reading.

Internal gateway ready

API URL, key and model name can be changed in JSON config or environment variables without rebuilding.

Audit and guardrails

Tool calls are logged, secrets are redacted, file writes show diffs, and destructive shell commands are blocked by default.

Configurable storage

Use local user storage, a shared drive, or any organization-specific path. No fixed K/D drive assumption.

A 股投研日报桥接

保留你现有的 stock_research 多 Agent 脚本，JL-Agent 负责把它变成用户可见、权限可控、可恢复定时任务的能力。

Deployment paths

同一个项目可以给开发者、管理员和普通员工使用。Python 模式适合维护，EXE 模式适合分发。

01

Python mode

Install requirements, initialize config, run the TUI or dashboard.

02

Windows EXE

Admin builds once with PyInstaller, then distributes xjlagent.exe.

03

Shared storage

Point personal and shared data to local or organization paths.

04

Internal model

Configure model gateway URL and key without changing the executable.
